**Maximum Subarray Sum Optimal Solution Using Kadane's Algorithm(It is part of DP)
~What is Kadane's Algorithm?
--Kadane’s Algorithm is an efficient method to find the maximum sum of a contiguous subarray in an array.
👉 It improves the brute force approach from O(n²) / O(n³) to : 🚀 O(n) time complexity

🧠 Intuition (Simple Words)
If the current sum becomes negative, it’s useless → reset it
Keep track of the maximum sum seen so far
