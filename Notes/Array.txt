Data Structure--
A data structure is a systematic way of organizing, storing, and managing 
data so that it can be used efficiently.
(along with the operations that can be performed on it efficiently)
A data structure is a way of organizing and storing data in a computer so 
that it can be accessed and modified efficiently.

Algorithms--
A finite, step-by-step procedure or set of instructions used to solve a 
specific problem or perform a task.

Array--
A linear data structure that stores a collection of elements of the same 
data type in contiguous memory locations.

Key Features--
1-Same data type (all elements must be similar)
2-Contiguous memory (stored next to each other)
3-Indexed access (each element has an index)
4-Fixed size (size defined at declaration)

Note: Arrays in C++ are implicitly passed by reference.

***To sort an array
sort(arr,arr+n);    
Arguments explained
arr → starting address of the array
arr + n → address just after the last element                      


---Why can't we use foreach loop in function in which the array is passed?
Because when an array is passed to a function in C++, it becomes a pointer, not a complete array.
A for-each loop needs the full array size to know how many elements to iterate over.
So this works in main():
int arr[5]={1,2,3,4,5};
for(int x : arr){
    cout << x << " ";
}
because the compiler knows the array size is 5.

But inside a function:
void fun(int arr[]){
    for(int x : arr){
        cout << x;
    }
}
it gives an error because arr is treated as a pointer and pointers do not store array size.
