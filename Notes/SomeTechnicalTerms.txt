Pseudocode is a simple, human-readable way of describing how a computer program 
or algorithm works — without using the exact syntax of a real programming language.
Pseudocode is an informal way of writing the steps of an algorithm using simple 
English-like statements mixed with programming logic.

---Reason behind the return 0 in int main()
main() is declared as:
int main()
The int means the function must return an integer value to the operating system.
return 0;
means:
"The program finished successfully."
Example
#include <iostream>
using namespace std;
int main() {
    cout << "Hello";
    return 0;
}
Here 0 indicates success.


IMPORTANT
****Suppose the return type is vector and we have created a vector to store the output and 
return it then the space complexity is still O(1) because the output array is required to 
return the answer. Space complexity counts only additional auxiliary space beyond the output.


//Input Problem

***CALL STACK
--The call stack is a special area of memory that keeps track of function calls while your program is running.
--Think of it like a stack of plates: the last function called is the first one to finish.
Call stack

┌─────────┐
│    C()  │  ← currently executing
├─────────┤
│    B()  │
├─────────┤
│    A()  │
├─────────┤
│  main() │
└─────────┘
Call stack = memory structure that stores information about active function calls.
